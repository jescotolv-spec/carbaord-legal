# CarBoard Legal

This repository contains the public legal documents for the CarBoard mobile application.

These documents are provided to comply with Apple App Store requirements and to inform users about how the app handles data and usage.

## Documents

- Privacy Policy  
  Describes what data is collected, how it is used, and how it is stored.

## Purpose

CarBoard is an application designed to help automotive service shops manage customers, vehicles, work sessions, and related operational data.

This repository exists solely to host publicly accessible legal documentation required for app distribution.

## Access

All documents in this repository are intended to be publicly accessible without requiring login.

They may be referenced from:
- The CarBoard mobile application
- Apple App Store listing

## Updates

These documents may be updated periodically to reflect changes in features, data handling, or legal requirements.

## Contact

If you have questions about these documents, you can contact the developer through the CarBoard application or associated business contact channels.
